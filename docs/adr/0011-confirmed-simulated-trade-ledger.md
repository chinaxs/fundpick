# ADR-0011：以已确认交易流水生成模拟持仓

状态：基础流水规则保留；日期与金额折算部分由 [ADR-0012](0012-record-real-platform-receipts.md) 更新。日期：2026-11-08。

旧版直接增删持仓，缺少卖出、费用与历史收益；历史净值缺失时回退最新净值，无法形成可核对的交易过程。

采用已确认交易记账：买入按含费金额、卖出按份额，预览后确认；移动平均成本结转，按基金汇总。暂不模拟交易申请、交易日历、清算与到账，因为当前公开净值和平台规则不足以可靠支持该状态机。

新流水保留成本和份额快照，写入按会员串行、request_key 幂等、确认校验预览版本。通过仅允许末笔作废和时间顺序追加，保持快照可信。代价是不能直接编辑中间流水或随意补入更早成交，界面明确说明纠错顺序。

旧持仓保留待核对，不自动迁为可信成交；逐笔确认迁移并支持作废恢复。使用现有 SQLAlchemy、Pydantic、数据库事务及 Python Decimal，不引入交易框架或额外依赖。

完整用户流程、计算口径与边界见 [模拟交易流程](../trading-flow.md)。
