# ADR-0013：金额与时间自动记账，保留费用依据和估算来源

状态：已接受，2026-11-08。补充 ADR-0012，用户不应手填可查询的净值或常规费率。

默认录入金额/卖出份额和实际下单时间。后端查询对应交易日的净值、公开申购/赎回费率表；申购按金额档位采用外扣法，赎回按同平台持仓的FIFO批次匹配持有期费率。年/月采用实际周年/月，不能统一按365天折算。管理费、托管费和销售服务费已计入净值，不再次作为交易费用扣减。

公开费率表缓存24小时，保留标准与特定来源渠道的优惠；只有用户明确选择该来源渠道才用对应公开优惠，不把优惠套给未知平台。历史费率、用户专享优惠、确认份额精度与持有期定义不一定能从公共数据还原，因此来源标记 estimated，保留 calculation_basis，并与receipt/旧calculated区分。未取得价格或无法明确匹配费率时保持待处理，不能以零费用或最近净值兜底。

自动记录是显式选择：申请表增加 automatic_processing，原人工待确认记录不静默转为自动成交。自动数据补齐在既有采集任务更新后和待处理清单查询时执行，当前不引入独立定时器或跨API进程隐式任务；规模扩大时再纳入任务中心。外部补查在会员写锁前执行，落库依旧使用会员锁、预览摘要和幂等请求编号。

界面采用现有Element Plus：大额输入与金额快捷按钮、北京时间摘要、按需打开的中文日期选择器、行内校验。自动查询齐全直接保存；人工回执无差异也直接保存，有差异才展示核对步骤。实际回执更正沿用末笔作废后重新录入，避免重复持仓。
