# ADR-0014：自动等待入账与统一交易记录

状态：已接受，2026-11-08。

日常记录不应要求用户补充成交结果。默认保存申请后，由系统查询申请对应的净值、交易费用及公开T+N确认周期，等待满足条件再入账；异常时才提供人工核对入口。站内自动计算来源保留，不能冒充已直接核验的平台交易。

正常状态为待入账→已入账。公开确认周期按证券交易日推进，取得净值并不代表立即确认；确认周期缺失则继续等待。公开推算的确认日与平台实际确认日分别保留，FIFO持有期在无实际确认日时优先使用公开推算日并注明。

待入账可以撤销本站记录，停止自动处理。本站不提供真实平台交易，因此撤销不发起外部撤单，不臆造所有平台的可撤时间。已入账只能进行本站记账纠错，按同基金有效流水倒序作废，不能把纠错作废称为外部撤单。

统一交易记录合并待入账、已入账、已撤销、已作废；申请转成交后不重复展示申请，成交作废和删除后也不能再次冒出关联申请。数据库UNION与LIMIT/OFFSET完成筛选分页，不取全量流水在Python分页。支持基金名称/代码、方向、状态、北京时间下单日期筛选；旧记录无下单时间时以录入日期筛选并注明。

只允许删除已作废交易或已撤销申请。删除从用户记录清单移除，以deleted_at保留请求编号的幂等墓碑，防止网络重试重新记账；不影响持仓收益。真实注销账号时清除含墓碑的个人数据。
