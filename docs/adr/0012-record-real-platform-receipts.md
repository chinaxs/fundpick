# ADR-0012：真实平台回执优先，申请与确认分离

状态：已接受，2026-11-08。补充并替代 ADR-0011 中“只记录确认日期、金额折算份额”的部分。

用户在其他平台实际购买基金，本站仅不提供交易执行。以最新净值代替申请对应日期、或金额除净值统一取整份额，会使记账与平台回执不一致，污染后续分析。

决定保存申请时刻、净值所属日、平台确认日及平台。普通境内场外基金采用核对过的证券交易日历、北京时间 15:00 截止；特殊品种或日历未知范围以回执日期和依据记录。净值未公布时保留待确认申请，不生成猜测成交，不因有官方净值就自动声称平台已确认。

按回执保存实际买入份额、费用、卖出净到账与编号，算术差异显式提示而不覆盖。成本按平台分别结转，组合再汇总。旧折算流水保留来源，客户端不再生成新的旧折算记录。为兼容旧接口，`confirmed_on` 保留字段名，但明确表示净值所属日；新增 `settled_on` 表示平台确认日。

本地日历覆盖 2025/2026，年度更新作为明确维护工作；超出范围拒绝自动规则。待确认、用户回执和旧折算分别存储，为未来 AI 提供可辨别来源，不将用户录入冒充外部核验。

详见 [交易流程](../trading-flow.md) 与 [项目代办](../TODO.md)。

界面简化补充：快速记录默认只填金额/份额与下单时间，平台可以暂缺，确认日可留空。自动模式遇特殊品种或日历未知时保留未知并允许保存，严格手动 cn_open 校验仍拒绝猜测。缺少信息以待补充状态表示，不以默认手续费或推算份额制造已确认数据。
