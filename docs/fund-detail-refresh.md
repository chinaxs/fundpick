# 基金详情数据更新

本修复已合并到开源`main`：历史净值更新、风险测算和重仓股行情作为公开基础功能维护。

## 本次问题

025196（广发创业板指数增强C）的基金快照已有2026-11-06净值0.8803，但历史曲线只有截至11月5日的269条数据。详情服务原来只在完全没有历史数据时补采，因此存量历史序列会一直停留在首次采集日期。

风险指标未采集；原雪球分析源对该代码抛出`KeyError: index_data_list`。原采集任务还使用内连接筛选已有1年指标的基金，完全缺少该指标行的基金会被漏过。

原重仓股只提供季报披露，没有接入股票最新涨跌；原始持仓市值单位为万元，API/页面却写为亿元。

## 实现

- 新增`fund_data_checks`及迁移`k2e6a4b8d901`。按需访问净值/持仓时检查持久化刷新时间；净值30分钟、季报6小时复查，失败5分钟后重试。基金与数据类型键串行，避免多个worker重复刷新。
- 取回完整净值历史并幂等更新，更新基金最新净值及日期；上游失败保留已有值。若快照披露日更新而历史源尚未跟上，可以按该日真实快照补一个净值点，日涨跌保持未知，不从单位净值反推。
- 页面先取得历史数据，再计算缺失风险。1/3/6月、1/3/5年和成立以来的风险按完整日涨跌幅测算，记录来源与基准日；不覆盖已有独立来源的完整风险指标或区间收益。
- 日收益按公开的日涨跌幅复利构建财富序列，避免分红造成单位净值下降被误当成亏损。最大回撤按财富序列峰谷计算，年化波动率为日收益样本标准差×√252；夏普为日均收益/日标准差×√252，明确采用无风险利率0。样本不足20个不年化，零波动不定义夏普。
- 成立时间不足、历史覆盖不足、较长缺口和缺失日涨跌幅分别说明，不强行填0或编造多年指标。
- `GET /portal/funds/{code}/holdings/quotes`批量查询前十大股票的腾讯证券行情。支持沪深北和5位港股代码，未知市场明确不支持。行情缓存60秒、失败20秒退避，最多512个代码；保留真实行情时间，非今日数据不显示成今日涨跌。
- 季报持仓和股票行情分开请求，行情加载失败不会隐藏持仓。页面可见时每分钟更新一次，明确“不是基金实时收益”；季报仍保留真实披露季度。重仓市值从万元转换为亿元。
- 历史表和图表共用同一日期范围，详情页取最多2000个点并展示最后日期；手机端表格内部滚动，标题操作和统计卡适配窄屏。
- 开发API增加3秒优雅退出超时，行情SSE长连接不会再使热重载无限等待。

## 025196验证

上游历史净值可取得270条，最后日期2026-11-06，单位净值0.8803，日涨跌−4.09%。11月9日的基金官方净值在当时上游尚未提供，没有用股票涨跌或估值替代。

近1年风险测算：最大回撤43.3653%，年化波动34.9862%，夏普−0.5545，基准日11月6日。3年区间明确显示“成立时间不足该区间”，因为该份额成立于2025-09-02。

实际行情接口取得十只重仓股当日涨跌并保留北京时间，例如宁德时代−2.19%、新易盛+2.27%；这些是当时查询结果，不是固定行情。持仓源仍只返回2026Q2，因此页面不宣称有2026Q3持仓。

## 验证与范围

独立临时MySQL测试库完整回归399项通过；新增刷新、风险测算、单位转换、行情时间与缓存失败检查。Ruff、mypy、前端类型检查与生产构建通过。真实浏览器验证025196净值日期、4张统计卡、10只重仓行情、成立不足提示和手机展示；没有向日常账本写入测试会员或交易记录。

上游数据源仍可能延迟或失败，测算结果与第三方平台的复权、采样及无风险利率口径可能不同。风险来源在每个区间明确标示；此处未声称替代平台回执或实现基金实时估值。
